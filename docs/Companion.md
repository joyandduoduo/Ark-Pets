# 原版基础上的角色陪伴定制

本分支直接使用原版 `ArkHomeFX`、`RootModule.fxml`、`Main.css` 和模型／行为／选项三个控制器。在原版基础上做加减法：模型名单缩减为11位；按角色分组外观；增加战斗模型与普通话陪伴语音。旧的简化表单窗口已撤下，兼容入口也转到原版面板。

## 使用

双击独立包中的 `打开角色陪伴.cmd`。

- **模型**：沿用原版搜索、随机、收藏、标签筛选和模型库面板。列表每位角色一行；左下的两个下拉框选择外观和基建／战斗正面／战斗背面。正在陪伴时可直接换装，保留进程和桌面位置。
- **行为**：顶部增加当前角色的普通话语音、间隔、音量和战斗动作；向下滚动仍有原版动作、交互、位置、多屏、过渡、重力与摩擦等设置。
- **选项**：原版缩放、帧率、画布、描边、透明度、阴影、窗口、节能、托盘退出行为等设置仍在。
- **启动／重启**：启动所选角色。已在陪伴时应用原版显示或物理设置，会退出并重启当前角色；换外观和模型直接生效，无须此步骤。其他角色继续运行。
- **退出**：遵循原版“退出启动器时同时退出桌宠”设置。希望关闭面板后继续陪伴，可在选项中关闭该项；最小化会隐藏到托盘。“让他休息”只退出当前角色。
- **语音**：默认普通话、每10～20分钟随机一句，可暂停和调整。一轮内不重复，多角色通过本地音频锁错开；手动可“现在说一句”。Misery来源中缺少基建与普通话语音，保留缺项。
- **自动活动**：默认45～120秒穿插一次有限日常／战斗动作，播完回到所选外观和模型；拖拽、手动模式、说话期间让路。原版允许坐下／躺下／交互／特殊动作的开关继续生效。除下述令的明确试用外，不自动选择死亡／倒下。
- **自动换装**：有多套外观时默认每30～60分钟换一次，同一角色保持进程、物理位置与朝向；可以关闭或点“换一套”。
- **台词气泡**：随原普通话录音显示原文，采用半透明切角面板、蓝白细线；气泡只显示说话者和台词，语音分类标签留在面板。点击气泡可收起，长句按进度翻页。三种主题可以预览。
- **选择轮播语音**：行为页点击此按钮，按来源筛选、搜索台词、逐条勾选／试听，立即按角色保存。全不选即保持安静；试听不改变勾选。新增的本体、异格和皮肤录音默认不混入原来10条陪伴语音。

语音库可通过下面的独立脚本扩充全部普通话录音（不扩充桌宠角色名单）：

```powershell
python docs/scripts/fetch_voice_library.py --catalog companion-data/catalog.json --metadata temp/voice-metadata --output companion-data
```

当前素材核验为608条：包括拉普兰德、德克萨斯、临光的本体，以及重岳「全能演员」、令「方遒卷」、荒芜拉普兰德「无序的谦卑」。每组38条，可混选。语音原件和台词仅保存在本地素材目录，不随源码提交。

精选模式的模型库管理改为素材来源、重新载入、验证所有74套模型、打开素材目录和导出精选压缩包，不拉取全员资源。直接运行原版 `DesktopLauncher` 仍保留上游完整模型库下载、更新与导入功能。公告可在原版公告按钮中查看，精选入口不自动弹出公告遮挡操作。

## 构建与素材

Java17，使用仓库的Gradle Wrapper：

```powershell
python docs/scripts/fetch_companions.py --output companion-data
python docs/scripts/package_companion.py --java-home C:/path/to/jdk-17 --output C:/path/to/companion
```

将 `companion-data` 放在输出目录。来源文件与SHA-256保持原样，不将游戏素材提交进源码仓库。

PRTS中24套模型的PNG被下采样，atlas仍保留原尺寸。精选入口在加载时将纹理适配到atlas声明尺寸，保留原有预乘透明度和原始文件；原版模型的加载不变。两种启动模式使用独立IPC端口组，防止误连现有原安装。

## 验证

`docs/checks/UpstreamCompanionCheck.java` 检查真正的原版模块及子进程；旧检查类名只保留为转发入口。测试使用隔离的素材目录链接和独立运行设置。`CompanionSmoke.java` 加载全部模型、导出原生渲染帧并解码语音。通用动作排除倒下／死亡，技能结束回待机。

### 令的长展示试用

令的二、三技能按 2 → 3 → 2 → 3 轮换；入场 Start → 普通待机 → 普攻一次 → 技能展示 → 正面 Die 退场 → 淡出回所选模型。背面没有 Die，普通待机后淡出。二技能施放两次，中间普通待机6～9秒；三技能为 Begin → 专属待机9～12秒 → Loop攻击一次 → 专属待机11～15秒 → End → 普通待机。待机按完整原生动画周期向上取整。正面末帧保持到淡出，避免 Die 后闪回 Idle。点击角色、手动换模型或关闭战斗可中止；其他角色保留短动作。

行为页的技能2／3按钮可从基建直接预览完整正面展示。四套衣服的实际骨架都没有独立 Skill_01，未伪造一技能动画。下载器只获取 Spine骨架、atlas及其中引用的纹理；模型内置效果可显示，独立游戏粒子、弹道与召唤物未集成，不代表完整战斗特效。

自动换装仍遵循用户间隔，默认30～60分钟；时间保存在角色的 `.schedule.json` 中，重启继续，改变换装开关或间隔才重新计时。到点后等待当前动作／语音结束，优先于下一次自动活动。面板显示下一次换装时间或等待状态。

`LingShowcaseResourceCheck.java` 校验四套衣服×正背面×二、三技能，共16种真实骨架组合，包含入场、退场末帧、姿态混合。`check_ling_showcase.py` 校验真实播放、完整回程、手动中止、重启保留换装时间及长展示结束后的到期换装。

`CompanionActivityCheck.java` 使用真实子进程验证自动换装、战斗归位、语音勾选与原录音试听、气泡稳定和跨进程碰撞排除。加速间隔仅在隔离测试目录中使用；正式默认保留10～20分钟语音和30～60分钟换装。

程序内检查、实际鼠标操作、扬声器听感、跨屏DPI和长期使用分别记录，技术通过不等于用户接受。
